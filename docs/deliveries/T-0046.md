## 状态与持久化

新增 TaskCandidateFrozen，保存 WorkspaceDelivery 和执行 manifest path/hash。候选只追加到 APPLIED attempt.events，新增 current_candidate/candidate_ready 派生属性，不增加 phase。负向核对撤销资格但保留原始事实；候选存在后拒绝范围交回。旧候选先按旧尝试路由进入 HISTORY_ONLY；当前首次和重复发布均先核完整历史 CAS，再在同一事务中写状态与历史。

所有转移登记在 transitions.py，PLANNING_REQUIRED 显式接入候选 handler，避免其既有默认 None 表项静默忽略错误候选。本卡无 SQL 表结构变化，无迁移；既有 JSON payload 容纳新事件，旧编码不补新字段。
