任务卡经 Claude 文字复核，运行时报告 `claude-opus-5-5`、终态 completed、进程退出 0；实际 effort 未报告，保留未知。意见已处理：复用实际原子迁移执行器；Problem None 仅属于 preflight；SQL 不存 phase，统一调用纯派生；按实际 T48 提交复核版本断言、38 个旧回放 ID、八份旧兼容字节及源文件哈希。独立复核补充 canonical 语义比较、旧收据不能补新 epoch，以及取消状态须同时满足 Finished 与实际停止。

## 验证记录

完整 `scripts/verify.sh` 五步通过：lint、format（207 文件）、typecheck（71 个源文件）、3,084 unit、51 replay。UTC 2026-11-17 02:06:47.804088 至 02:23:47.467409；unit 1017.86 秒、replay 1.25 秒。新 unit 共 197 个；新 replay 为六组场景的 core/sqlite 各一个参数，以及独立防零收集用例，共 13 个。原有 38 个回放及其输入/驱动保持。源码与新测试的独立只读审核未发现剩余阻断，53 个旧转移定义/常量的 AST 与基线一致。

保留的早期结果：基线新 unit/replay 均因缺模块而 collection error，未执行到行为断言；首次附加 `-q` 收集旧回放只返回文件级数量，检查本身通过但外部采集断言失败，随后 `--collect-only` 得到全部 38 个 ID；首轮新 unit 检查被新测试使用 pytest 保留参数名 `request` 阻断，改名 `control_event` 后全部原案例和断言保留并通过。日志均在仓库外 T49 目录，没有覆盖失败记录。

源码审核修正了三点：新 codec 显式核嵌套 candidate.kind，不改旧 decoder；实现尝试坐标拒绝 True 冒充 1；普通观察的非法序号先于缺 stage 错误拒绝。迁移测试使用真实 v4 的十四旧表关联行，逐值比较 schema、TEXT/BLOB 和 typeof；故障迁移、两连接预留竞争和多处提交前写失败均有独立用例。提交后外层异常的用例确认记录可能已完整落盘，不宣称回滚或自动补偿。

独立测试审核补强了两个真实缺口：命令预留的同长度历史内容变化现直接改变已存 envelope，而非重复测试历史尾增；增加 Finished 后 AWAITING_EVIDENCE 接受取消及 FAILED 后迟到取消只入历史。8 个定向用例通过，完整验证再次覆盖。首次 lint 的 TRY004/SIM114/I001 通过明确类型错误、保持 Started 的专用授权 ValueError、合并等效编号检查和整理新测试 import 修复；随后 mypy 的可选编号参数问题通过保留原校验逻辑、将验证函数参数标注为 object 修复。未添加 noqa、放宽检查或削减断言。
