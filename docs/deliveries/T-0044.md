## 边界

输出解析只接受当前 task hash 的四字段 JSON。completed 不得报告额外路径；scope_blocked 必须说明阻塞并列出具体安全相对路径。路径是字面量，不是 scope pattern，保留 `[slug]`、`(group)` 等实际名称；不扩写入范围、不解析说明文字为测试或权限证明。

binding 只连接仍处于 T43 live scope 的新 launch 与尚无 operation/resource 的实际 ImplementationRuntimeAdapter。它检查公开配置、工作区、schema 和 logdir 并消费一次 launch 资格。封存只从同一 adapter 读取实际 result 和 receipt；普通副本共享一次封存状态，不接受旧 owner 或同路径的替换实例。

唯一文件位于本 attempt 的 T43 logs：`.seal-attempt.json` 与 `execution.json`。index 只是后者的别称。首次样本与实际报告保持，不允许在失败后换一份更完整的收据重封。context 初始 manifest 不变，也不作为执行结束 receipt。

未知 stop 分支不调用 workspace scanner 或会间接扫描的 T43 inspector；最终 digest 保持 None。只有实际 receipt 已报告停止，才检查完整 context 并实际扫描最终工作区。未封存日志不读到 EOF、不补 hash；本模块只对已完整 sealed 的日志按已报告 byte_count 作有界核验。既有 Recorder 的 receipt getter 仍有自己的 closed-file EOF 核验，本卡不改这层或扩大有界承诺。

manifest 分列 actual TurnResult、EnvironmentInfo、原 runtime observations、完整 ownership receipt、派生事实、初始/最终 digest 与解析后的 report。requested model/effort 和环境能力列表不能填入实际未知值。非零实际退出不改写模型 Completed；取消后 core result 为空也不删除真实 Completed.result。

实际 terminal/exit 对照同 attempt 的完整历史，包括 HISTORY_ONLY。证据绑定首次样本后的历史前缀；允许只追加的旧尝试结果或未接受的迟到取消，同时重新检查当前尝试、冲突事件和永久撤销。旧历史不能仅凭改变全 history 长度使当前合格执行失败。

只有完整正向证据才具备 qualified；合法 scope_blocked 可 qualified，但不能 delivery_eligible。host 依序保存真实 TaskReconciled 和精确 TaskScopeBlocked，旧工作区原地保留。归档核验缺少正向数据库 path/hash 锚点、停止未知、文件/最终摘要变化或负向 manifest 时均拒绝，不能产生新的 binding。后续候选消费者仍须检查当前 core 状态和 inspector 的 delivery_eligible。

## 实现期复核

独立只读复核发现两处边界问题并修正：数据库 task input 读取移出输出解析的异常捕获，宿主读取/解码错误继续抛出原异常，不伪装成模型 validation_error；正向归档在打开 execution 文件前先核对 Prepared 中原 context 的身份与模式，避免先读到另一个 sibling 目录的文件。两处均不改变状态机、数据库或旧接口。

证据模块首轮完整定向检查为 143 passed、1 failed：错误 run_id 先被用于查询数据库并产生 KeyError。修复在任何此类查询前显式核对 caller run_id 与 issued launch 的原 run_id，一致后才继续；不捕获或掩盖合法运行中的宿主 KeyError，也未放宽测试期望。

静态检查首轮指出两个异常类型约束和一处 Any 返回类型，按输入类型/精确对象 schema 及显式类型转换修正后，lint、typecheck 均通过。原失败日志和修复后输出一起保留。
