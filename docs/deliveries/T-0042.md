## 交付边界

显式 managed 标记保持旧模板及位置参数可用，禁止两种执行链互相切换。完整 WorkspaceRecord 包括二进制控制文件身份/内容，hex 编码区分未知、空 bytes 和非 UTF-8 bytes。有序备选策略独立冻结，不能从选中处截断的 selection_history 重建。

新准备、环境观察和证据拒绝事件进入统一转移表。managed 实际事件单独保存；拒绝产物不覆写原模型成功、结果或退出。最终工作区扫描未知为 None，初始 digest 不作为替代；交付门槛要求实际退出、最新停止、最终 digest 和成对执行 manifest receipt。详见 [Managed 实现尝试的持久化契约](../task-execution.md)。

TaskStore 的 reserve 在同一 BEGIN IMMEDIATE 中核对完整历史 CAS、当前状态、固定策略、工作区所属仓库和完整派发决定，成功后一次写状态及两条历史。公共单事件 API 不允许收养已有 Started。纯 reserve 与数据库 reserve 使用同一转移逻辑。

独立代码复核补齐两个 managed 专用边界：缺模型终态时仍保存真实模型退出但不推断停止；范围阻塞进入 planning_required 后继续记录最新 Reconciled，防止状态留有旧停止值。这两项均保持 legacy 行为，并追加单元测试和新 managed 回放。

没有新增 TaskPhase、FailureCategory 或 SQL 表。已有 JSON payload 只扩新可选字段，旧必需字段缺失仍失败。legacy Diagnostic 的 HISTORY_ONLY、旧编码形状和旧四个回放保持；新场景另外完整核对 managed receipt 与事件，不以缩减投影掩盖新字段。
